Copy the `riscy` folder to the board's SD card as `/home/xilinx/jupyter_notebooks/riscy` and run `base_riscy.ipynb`.

- `overlays/` holds the bitstream of our final design.
- `mem_files/` holds the program that the notebook loads. To run another version, copy `code.coe` and `data.coe` from `software/bin_files/` or from a `software/Final_codes/*/bin_files/` folder into it.
